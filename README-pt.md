# dsh-plugin-search-plugins

> Quick Search (Ctrl+F) and smooth jump navigation for the plugin manager page in DeepSeek Harness.

## 🌟 功能特色
- Ctrl+F / Cmd+F quick search.
- Smooth scrolling and native highlight.

## 📁 目录结构
- package.json, index.js, client.js, icon.svg, locale/

## 🚀 手动安装与启用方法
- dsh plugin --profile desktop add <path>

## 🧪 验证与体验
- Press Ctrl+F in the plugins page to search and jump.
